Como publicar no GitHub Pages

Para disponibilizar este Quiz online gratuitamente para seus colegas, siga os passos abaixo:

  1. 1. Salve este código:
    Crie um arquivo chamado exatamente index.html no seu computador e cole todo este código dentro dele.
  2. 2. Crie um Repositório no GitHub:
    Acesse seu GitHub, clique em New Repository, escolha um nome (ex: quiz-ciencias) e deixe o repositório como Public.
  3. 3. Envie o arquivo index.html:
    Clique no botão Upload files dentro do seu repositório no GitHub, arraste o arquivo index.html e confirme em Commit changes.
  4. 4. Ative o GitHub Pages:
    No repositório, vá em Settings > Pages (no menu esquerdo). Em Build and deployment / Branch, selecione main (ou master) e clique em Save.
💡 Em 1 a 2 minutos, o GitHub gerará um link público parecido com: https://seu-usuario.github.io/quiz-ciencias/
